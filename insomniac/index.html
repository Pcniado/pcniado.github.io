Luna Engine IO Tools

Python Blender 5.0+ GPLv3

A Blender add-on for Luna Engine assets. Imports and exports compiled .model files and .animclip animations directly inside Blender, so meshes and animations can go out of the game, get edited, and go back in.

More info
  • Import one or more compiled .model files; export selected model hierarchies back to Luna Engine format.
  • Import .animclip files and apply them to an existing armature or camera.
  • Shape key management for Morph2 deformations.
  • Ziva2 rig evaluation tools.
  • Camera animation support alongside skeletal animation.

Requires Blender 5.0.0 or newer. Python 3.x ships with Blender — no external dependencies.

Install download the repo, put the files in a folder named luna_engine_io_tools, then install it from Blender's Add-ons preferences.

Custom Suit Damage Patcher

Tool Spider-Man 2 Drag & Drop

A command line tool that adds suit damage support to custom .suit mods. It processes the suit's meshes and materials automatically, for custom suits where the game's damage effects are missing, mismapped or invisible in gameplay.

More info
  • Drag and drop a .suit, .modular, or even a .zip / .rar / .7z onto SuitDamageTool.exe.
  • The tool walks the meshes and materials and writes the damage mapping for you.
  • Install the newly generated file with Overstrike.

Note the same model work also enables x-ray behaviour on custom suits.

Atmosphere Slots

Core Mod Spider-Man 2 Overstrike

The groundwork that lets the community add brand new atmospheres to the game. Atmosphere Slots Core adds extra atmosphere slots while leaving every vanilla weather slot intact — it's the requirement most custom atmosphere mods on Nexus are built on.

More info
  • Atmosphere Slots Core — required by any mod that adds a new atmosphere slot. Vanilla slots stay untouched.
  • Atmosphere Slot Converter — experimental, for mod users: converts existing atmosphere mods over to the new slots.

Requires Script Support enabled in Overstrike.

DAT1-GUI

C# .NET 7 GPLv3

A standalone toolkit for working with the mod files used in PC ports of Insomniac Games titles — a heavily extended take on Tkachov's original Modding Tool.

More info
  • Project system so your work is preserved between sessions.
  • Sandboxed Python scripting.
  • Texture viewer and config editor.
  • .wem audio naming plus a built-in player (vgmstream).

Requires .NET 7.0 Desktop Runtime.

Start grab the newest build from Releases, run DAT1-GUI.exe, then open a table of contents file from the File menu.
