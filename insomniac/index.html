Luna Engine IO Tools

Pulls models and animations out of the game and puts them back, without leaving Blender. Compiled .model files and .animclip animations both round-trip, with the rig, shape keys and camera data coming along.

More info
  • Import one or more compiled .model files; export selected model hierarchies back to Luna Engine format.
  • Import .animclip files and apply them to an existing armature or camera.
  • Shape key management for Morph2 deformations.
  • Ziva2 rig evaluation tools.
  • Camera animation support alongside skeletal animation.

Requires Blender 5.0.0 or newer. Python 3.x ships with Blender — no external dependencies.

Install download the repo, put the files in a folder named luna_engine_io_tools, then install it from Blender's Add-ons preferences.

Custom Suit Damage Patcher

Custom suits usually come out with damage broken — effects missing, mapped to the wrong spot, or just invisible in gameplay. Drop the .suit on the exe and it rewrites the meshes and materials so the damage lands where it should.

More info
  • Drag and drop a .suit, .modular, or even a .zip / .rar / .7z onto SuitDamageTool.exe.
  • The tool walks the meshes and materials and writes the damage mapping for you.
  • Install the newly generated file with Overstrike.

Note the same model work also enables x-ray behaviour on custom suits.

Atmosphere Slots

Adds new atmosphere slots on top of the vanilla ones, so a custom atmosphere gets its own slot instead of overwriting a stock weather state. Three pieces: an SDK for building atmospheres, a core mod everyone installs to run them, and a converter for older mods.

More info
  • Atmosphere Slots SDK — for mod authors. The kit for making an atmosphere that lives in its own slot.
  • Atmosphere Slots Core — for everyone. Required by any mod that adds a new atmosphere slot; vanilla slots stay untouched.
  • Atmosphere Slot Converter — experimental. Moves existing atmosphere mods over to the new slots.

Requires Script Support enabled in Overstrike.

DAT1-GUI

Open up the asset archives behind the PC ports and actually work in them — textures, configs and audio in one window, with Python scripting for when clicking through gets old. Built on top of Tkachov's original Modding Tool.

More info
  • Project system so your work is preserved between sessions.
  • Sandboxed Python scripting.
  • Texture viewer and config editor.
  • .wem audio naming plus a built-in player (vgmstream).

Requires .NET 7.0 Desktop Runtime.

Start grab the newest build from Releases, run DAT1-GUI.exe, then open a table of contents file from the File menu.
