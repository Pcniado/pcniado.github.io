# Screenshots

Drop an image in this folder and the matching card on `/insomniac` picks it up
automatically on load — no code changes needed.

The filename matches the card's anchor, so the image for
`/insomniac#lunaengineio` is `lunaengineio.webp`:

| file                 | card                       |
| -------------------- | -------------------------- |
| `lunaengineio`       | Luna Engine IO Tools       |
| `suitdamagepatcher`  | Custom Suit Damage Patcher |
| `atmosphereslots`    | Atmosphere Slots           |
| `dat1gui`            | DAT1-GUI                   |

`.png`, `.jpg` and `.webp` all work (checked in that order). Landscape, roughly
16:9, looks best. Cards without an image simply render without one.

Current images come from the mod pages on Nexus.

The same image is the link preview for that tool's page under
`insomniac/<slug>/`, so it is worth keeping them landscape and legible small.
